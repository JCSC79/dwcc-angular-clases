# 📚 Custom Directives

## 🎯 Objetivo
Aprender sobre **@Directive decorator** en Angular.

## 📚 Conceptos clave
- **@Directive decorator**
- **manipulación DOM**
- **directivas estructurales**

## 🔍 Ejemplo clave
```typescript
@Directive() personaliza comportamiento de elementos
```

## 🚀 Cómo ejecutar
```bash
npm install --legacy-peer-deps
ng serve
```

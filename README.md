# 📚 Conditional Rendering with ngIf

## 🎯 Objetivo
Aprender sobre ***ngIf directive** en Angular.

## 📚 Conceptos clave
- ***ngIf directive**
- **renderizado condicional**
- **control DOM**

## 🔍 Ejemplo clave
```typescript
*ngIf="condicion" muestra/oculta elementos según condición
```

## 🚀 Cómo ejecutar
```bash
npm install --legacy-peer-deps
ng serve
```

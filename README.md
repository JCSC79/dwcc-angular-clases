# 📚 List Rendering with ngFor

## 🎯 Objetivo
Aprender sobre ***ngFor directive** en Angular.

## 📚 Conceptos clave
- ***ngFor directive**
- **iteración de listas**
- **renderizado dinámico**

## 🔍 Ejemplo clave
```typescript
*ngFor="let item of lista" recorre arrays y crea elementos
```

## 🚀 Cómo ejecutar
```bash
npm install --legacy-peer-deps
ng serve
```

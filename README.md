# 📚 Output Component Communication

## 🎯 Objetivo
Aprender sobre **@Output decorator** en Angular.

## 📚 Conceptos clave
- **@Output decorator**
- **hijo a padre**
- **EventEmitter**

## 🔍 Ejemplo clave
```typescript
@Output() evento = new EventEmitter(); evento.emit(valor);
```

## 🚀 Cómo ejecutar
```bash
npm install --legacy-peer-deps
ng serve
```
